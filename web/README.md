

Полный стек проекта с ботом на Node.js, API на FastAPI и фронтендом на Next.js, а также базой данных PostgreSQL.

---

## Структура проекта

```text
.
├── bot                  # бот на Node.js
├── db                   # PostgreSQL, MongoDB и скрипты инициализации базы данных
├── docker-compose.yaml  # Оркестрация всех сервисов через Docker Compose
├── fastapi              # Backend API на FastAPI
├── nextapp              # Фронтенд на Next.js (TypeScript)
````

---

## Описание сервисов

* **bot/** – Макс бот на Node.js.
* **fastapi/** – Backend API на FastAPI.
* **nextapp/** – Фронтенд на Next.js (TypeScript).
* **db/** – Директория для баз данных и вспомогательных скриптов.
* **docker-compose.yaml** – Главный файл для запуска всех сервисов через Docker Compose.

---

## Требования

* Docker >= 20.x
* Docker Compose >= 2.x

---

## 1️⃣ Клонирование проекта

1. Перейдите в директорию, где хотите разместить проект:

```bash
cd /path/to/projects
```

2. Клонируйте репозиторий:

```bash
git clone https://github.com/dencamenew/VSUET.git
```

3. Перейдите в папку проекта:

```bash
cd VSUET
```

---

## 2️⃣ Запуск проекта через Docker

Соберите и запустите все контейнеры в фоновом режиме:

```bash
docker compose up -d --build
```

* `--build` – пересобирает образы перед запуском.
* `-d` – запускает контейнеры в фоне.

---

## 3️⃣ Остановка проекта

Остановить все контейнеры и удалить тома и "зависшие" контейнеры:

```bash
docker compose down --volumes --remove-orphans
```

## 🤖 MAX MiniApp Бот — Руководство пользователя

Добро пожаловать! Этот бот предназначен для быстрой и простой авторизации в цифровой образовательной платформе через **MAX MiniApp**.

Здесь вы узнаете, как пользоваться ботом, какие команды использовать и чего ожидать на каждом шаге.

В проекте используется tunnel Cloudflare, приложение можно тестировать в мессенджере MAX на любом устройстве.

@t173_hakaton_bot - бот в максе

---

## 📥 Как начать

1. Перейдите в чат с ботом в MAX MiniApp.
2. Введите команду:

```
/start
```

Бот приветствует вас и показывает, что можно делать дальше:

* `/auth` — войти в аккаунт
* `/logout` — выйти из аккаунта

---

## 🔐 Вход в систему (Авторизация)

Для входа используйте команду:

```
/auth
```

Бот проведёт вас пошагово:

1. **Фамилия** — бот попросит ввести вашу фамилию.
2. **Имя** — бот уточнит имя.
3. **Пароль** — вводим последний шаг.

Данные для студента: 
   - Фамилия: Петров
   - Имя: Иван
   - Пароль: petrov123

Данные для преподавателя: 
   - Фамилия: Маслов
   - Имя: Александр
   - Пароль: maslov123

После успешного ввода данных бот подтвердит вход в аккаунт:

```
✅ Вы успешно вошли в аккаунт!
🚀 Перейдите в приложение
```

Теперь ваш аккаунт привязан к вашему профилю в MAX MiniApp, и вы можете пользоваться платформой.


**Важно!** Для тестирования отметки посещаемости через QR-code необходимо использовать разные учётные записи MAX для аккаунта студента и преподавателя.

---

## 🚪 Выход из аккаунта

Чтобы выйти из системы, используйте команду:

```
/logout
```

Бот проверит, авторизованы ли вы, и сообщит о результате:

```
🚪 Вы успешно вышли из аккаунта.
```

---

## 🔄 Повторная авторизация

Если вы уже были авторизованы и попробуете снова ввести `/auth`, бот сообщит:

```
⚠️ Вы уже авторизованы.
```

и покажет имя и роль пользователя.
Чтобы войти под другим аккаунтом, сначала выполните `/logout`.
